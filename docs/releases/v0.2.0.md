# AtlasRV v0.2.0

AtlasRV v0.2.0 turns the repository into a causal, auditable, multi-asset
relative-value research platform suitable for technical interviews and extension.

Highlights:

- causal Kalman, expanding OLS, and rolling OLS hedge-ratio models;
- purged walk-forward evaluation with next-bar execution;
- decomposed two-leg costs, borrow, financing, and nonlinear impact;
- FDR-controlled diagnostics and explicit PASS/REVIEW decisions;
- ex-ante regime attribution and correlation-aware portfolio construction;
- immutable SHA-256 data snapshots and machine-readable research bundles;
- real observed FRED stress study across equity, rates, credit, FX, crypto,
  commodities, and volatility;
- public GitHub Pages dashboard generated only after all quality gates pass;
- Python 3.11–3.13 CI, Docker, typed package, tests, and build validation.

The FRED study retains REVIEW relationships in its diagnostics while allowing only
PASS sleeves into the headline portfolio. Several series are indices, yields,
spreads, or reference levels, not executable total-return instruments. Results are
research evidence, not a live profitability claim or investment advice.
