# AtlasRV v0.2 design notes

Version 0.2 turns the original pair-research demo into a broader research platform.

## 1. Model risk is visible

Kalman, rolling OLS, and expanding OLS implement the same one-step result contract.
The comparison command holds every downstream choice constant. A better backtest
can therefore be attributed to the hedge estimator rather than to a hidden threshold
or cost change.

Expanding OLS is used instead of a full-sample static regression because a
full-sample coefficient would leak future observations. It is the causal benchmark
for a slowly changing relationship.

## 2. Costs reconcile

For each sleeve and date:

gross return
minus commission
minus half-spread
minus slippage
minus impact
minus borrow
minus financing
equals net return.

Impact is quadratic in per-leg turnover. Borrow applies only to short held notional.
Financing applies to gross held notional. The assumptions remain simplified but
are explicit, stressable, and serialised.

## 3. Selection risk is controlled

A conventional 5% cointegration threshold applied to many candidates creates false
discoveries. AtlasRV computes Benjamini-Hochberg q-values across the registered
universe and never allows that correction to weaken a pair-level rejection.

This does not solve data snooping from repeatedly changing the universe. The config
and immutable data snapshot make that human decision auditable.

## 4. Diversification is measured

Inverse-volatility weights can allocate heavily to several differently named sleeves
that share the same risk-off factor. Version 0.2 penalises high trailing absolute
correlation, caps individual sleeves, reports the effective number of bets, and
attributes allocation across asset classes.

The asset-class view is an allocation mix, not a full factor model. Directional
beta, duration, convexity, vega, and liquidity limits remain a future extension.

## 5. Regimes are descriptive and causal

Volatility and trend labels use rolling statistics shifted by one bar. Performance
is then grouped by the label known before each return. These labels explain where
a strategy worked; they are not forecasts.

## 6. Every run is inspectable

The research bundle now contains:

- canonical input prices and their SHA-256 manifest;
- pair-level states, positions, cost components, and returns;
- portfolio weights and asset-class mix;
- diagnostics with p-values, q-values, and rejection reasons;
- walk-forward parameter choices;
- regime labels and conditional metrics;
- Markdown, HTML, JSON, CSV, and static chart outputs.
